Text in the file is Godot code that you want to be able to call as a one-time trigger.

You call the mod by its name.

For example, say_hello.godot_mod_one_time:
`⚙️say_hello`

Avoid using loops; you don't want to stack them.

Don't forget to kill it in your code.
The node is automatically destroyed after N seconds.

They are not restriction on Godot Modding.
So feel free to use any static method that you know existe in your version of GOMI.
